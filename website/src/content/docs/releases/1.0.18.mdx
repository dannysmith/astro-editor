No significant user-facing changes.

- **Astro 7 support** – Projects on Astro 7 are now tested and fully supported, alongside Astro 5 and 6.
- **Fixed nullable fields showing as text inputs** – Newer versions of Zod (used by Astro 7, and by fresh Astro 6 installs) describe optional fields like `z.number().nullish()` differently, which caused nullable number and boolean fields to appear as plain text inputs. They now show as number inputs and toggles again.
- Upgraded dependencies.

Preferences are about you rather than a project, and apply to every project. A project's own settings are in [Project Settings](/project-settings/), which the Preferences sidebar links to when a project is open. [How settings work](/project-settings/#how-settings-work) explains the difference.

Open Preferences with <Kbd mac="Cmd+," windows="Ctrl+," /> or from the app menu.

## General

The pane starts with a **Global Preferences** note, as a reminder that these apply to every project.

![The General preferences pane](../../assets/prefs-general.png)

**IDE command**: the command that opens your code editor for "Open in IDE", like `code` or `cursor`, or its full path, like `/usr/local/bin/nvim`. See [IDE Integration](/file-management/ide-integration/).

**Theme**: Light, Dark or System, which follows your Mac's appearance.

**New file type**: whether new files are Markdown (`.md`) or MDX (`.mdx`). A collection can set its own in [Project Settings](/project-settings/#new-files).

### Appearance

**Heading colour in light mode** and **Heading colour in dark mode**: the colour of Markdown headings in the editor, each with a **Reset** button.

**Editor font size**: the size of text in the editor, in pixels (default 18). The rest of the editor's typography scales from it.

### Editor

**Auto-save delay**: how long after you stop typing the file is saved: 1, 2, 5 or 10 seconds (default 2). See [Auto-save](/editor/overview/#auto-save).

## Advanced

For troubleshooting: the version numbers, the folder your preferences are stored in, and **Reset All Preferences**. See [Advanced Preferences](/reference/advanced-preferences/#the-advanced-tab).
